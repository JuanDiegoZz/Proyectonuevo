CONECTA RURAL EMPRESARIAL - PORTABLE
Windows 10 / 11 de 64 bits (x64)

1. Extrae TODO el ZIP a una carpeta local, por ejemplo Documentos.
2. Abre INICIAR.cmd. Espera a que aparezca la ventana del navegador.
   Si no se abre, copia en tu navegador la direccion de la consola.
3. Deja la consola abierta mientras uses la demo.
4. Para terminar, ejecuta CERRAR.cmd desde la misma carpeta.

No necesitas instalar Node.js ni npm. Puedes desconectar internet.
Utiliza un navegador moderno (Edge, Chrome o Firefox).
Si Windows restringe la ejecucion de programas, consulta a quien administre el equipo.

Tu progreso se guarda en el navegador usado. Para conservarlo entre sesiones,
usa el mismo navegador, perfil y URL. Si el puerto habitual esta ocupado,
el programa usa otro puerto: el navegador lo trata como una sesion separada.
Al cambiar de computadora se inicia con los datos de demostracion.
Para volver al estado inicial, abre Configuracion y elige Restablecer demo.

runtime/ contiene el ejecutable oficial de Node.js y su licencia.
app/licenses.json y app/map-license.txt describen los recursos incluidos.
